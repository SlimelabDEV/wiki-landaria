# 🪓 Les compétences (Skills)

Les **compétences** progressent en jouant : miner, récolter, pêcher ou combattre vous permet de gagner de l'expérience dans l'activité correspondante. En montant de niveau, vous améliorez vos **statistiques** et débloquez des **capacités**.

:::tip Compétences et métiers
Les compétences se consultent avec **`/skill`**. Pour les salaires, les collections et les améliorations, ouvrez **`/job`** et consultez la page [**Métiers & Salaires**](/docs/gameplay/jobs).
:::

---

## 📖 Consulter vos compétences

Ouvrez le menu avec :

```text
/skill
```

Les commandes `/skills` et `/sk` ouvrent également ce menu.

Choisissez une compétence pour retrouver :

- Votre **niveau**, votre expérience et votre progression vers le prochain niveau.
- Les **statistiques** améliorées par cette compétence.
- Vos **capacités passives**, qui apportent des bonus pendant vos activités.
- Votre **capacité de mana**, avec son effet, son coût et son temps de récupération.

Les conditions de déblocage et les prochains bonus sont indiqués directement dans le menu. Continuez à pratiquer l'activité correspondante pour progresser !

:::info Alchimie
Sur Landaria, vous pouvez utiliser jusqu'à **20 alambics simultanément par joueur** pour pratiquer l'alchimie.
:::

## ✨ Utiliser les capacités de mana

Certaines compétences donnent accès à une capacité spéciale liée à votre outil ou à votre arme :

| Compétence | Outil ou arme | Effet de la capacité |
| --- | --- | --- |
| **Fermier** | Houe | Replanter automatiquement les cultures. |
| **Bûcheron** | Hache | Couper les arbres plus rapidement. |
| **Mineur** | Pioche | Accélérer temporairement le minage. |
| **Fouilleur** | Pelle | Creuser plusieurs blocs voisins. |
| **Combattant** | Épée | Augmenter temporairement la vitesse d'attaque. |
| **Archer** | Arc | Renforcer vos tirs. |
| **Pêcheur** | Canne à pêche | Blesser une créature accrochée à votre ligne. |
| **Défenseur** | Bouclier | Absorber des dégâts. |

Pour les outils et l'épée, faites un **clic droit** pour préparer la capacité, puis effectuez l'action correspondante. Pour l'arc, le bouclier et la canne à pêche, la préparation se fait au **clic gauche**. Le message affiché en jeu vous indique quand votre capacité est prête.

:::info Avant de l'utiliser
La capacité doit être **débloquée**, vous devez disposer de suffisamment de **mana** et son **temps de récupération** doit être terminé. Consultez sa description dans `/skill` pour connaître les conditions exactes.
:::

---

## 💧 Comprendre la mana

La **mana** est la réserve d'énergie utilisée par ces capacités. Elle est consommée lors de leur utilisation, puis se régénère avec le temps.

La statistique **Sagesse** augmente votre réserve maximale de mana. Le menu des compétences indique les statistiques que vous pouvez améliorer en progressant.

Utiliser vos capacités de mana fait également progresser la compétence **Sorcier**.

---

## 🧪 Consulter vos bonus d'expérience

Dans le menu des compétences, survolez le bouton **« Vos bonus XP actifs »** pour retrouver vos bonus d'expérience et le temps restant de vos potions actives.

Ces bonus vous aident à monter vos **compétences**. Les potions qui augmentent vos **gains d'argent** se consultent séparément dans le menu `/job`.

---

## 💰 Quel lien avec les métiers ?

Votre niveau dans la compétence associée à un métier augmente son **salaire de base**. Par exemple, progresser en **Mineur** améliore vos gains du métier Mineur.

Le bonus est de **+0,3 % par niveau** : au niveau 50, cela représente **+15 %**. Vous pouvez retrouver votre bonus actuel dans la fiche du métier et le détail de chaque action dans `/job`.

Les **collections de métiers** ont leur propre progression. Pour découvrir les salaires, les quotas, les améliorations et la quête journalière, poursuivez sur la page [**Métiers & Salaires**](/docs/gameplay/jobs).
